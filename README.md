## 📖 Sobre o Projeto

**Fruit Slash AR** é um jogo de ação arcade moderno, inspirado nos clássicos jogos de fatiar frutas, mas trazido para a próxima geração através da Realidade Aumentada (AR). Utilizando a câmera do seu dispositivo e algoritmos de visão computacional, o jogo mapeia os movimentos das suas mãos no mundo real e os traduz para uma lâmina virtual incrivelmente ágil na tela.

Prepare-se para cortar maçãs, melancias e laranjas virtuais flutuando pela sua sala! 

---

## ✨ Funcionalidades Incríveis

- **🤲 Rastreamento de Mãos em Tempo Real:** Use suas mãos reais para controlar a lâmina virtual. Sem necessidade de controles adicionais!
- **📸 Realidade Aumentada (AR):** As frutas aparecem no seu ambiente real através da câmera.
- **⚡ Físicas e Partículas Realistas:** Sinta o impacto de cada corte com animações e efeitos de partículas fluidos.
- **🏆 Sistema de Pontuação:** Faça combos e veja sua pontuação subir.
- **🤖 Integração de IA (Gemini API):** Análise inteligente e dinâmicas avançadas de jogo com processamento no servidor via Gemini.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com uma stack moderna e robusta:

* **[React 19](https://react.dev/)** - Biblioteca principal para construção da interface.

### 🧠 Inteligência & Backend
* **[Google Gemini API](https://ai.google.dev/)** - Utilizado para processamento do lado do servidor e capabilities avançadas.
* **[Express](https://expressjs.com/)** - Servidor leve para gerenciar rotas de API.

## 🚀 Como Começar

Siga os passos abaixo para rodar o projeto localmente:

### Pré-requisitos
- Node.js (v18+)
- npm ou yarn
- Expo Go (app instalado no seu smartphone)

### Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/fruit-slash-ar.git
   cd fruit-slash-ar
   ```

2. **Instale as dependências da raiz (Web/Servidor):**
   ```bash
   npm install
   ```

3. **Instale as dependências do app Mobile:**
   ```bash
   cd mobile-expo
   npm install
   ```

4. **Configuração de Variáveis de Ambiente:**
   - Copie o arquivo `.env.example` para `.env` na raiz do projeto e insira sua chave da API do Gemini.
   ```bash
   cp .env.example .env
   ```

5. **Execute o projeto Mobile (Expo):**
   ```bash
   npx expo start
   ```
   > Escaneie o QR Code gerado no terminal com o aplicativo **Expo Go** no seu celular para testar a experiência de câmera/AR.

6. **Execute o ambiente Web de Desenvolvimento (Opcional):**
   Na raiz do projeto, execute:
   ```bash
   npm run dev
   ```

## 🎮 Como Jogar

1. Abra o aplicativo através do Expo Go.
2. Dê as permissões necessárias de acesso à **Câmera**.
3. Posicione seu celular ou tablet em um local estável ou segure com uma mão.
4. Mova sua mão na frente da câmera! Uma trilha luminosa seguirá seus movimentos.
5. Fatie as frutas que aparecerem na tela antes que elas caiam. 
6. Cuidado com as bombas! 💣
